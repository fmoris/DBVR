# Memoria 2026-04-16

## Resumen de la Sesión
Hoy se han alcanzado dos hitos críticos para la estabilidad y escalabilidad del proyecto DBVR: la fijación definitiva del sistema IK para el nuevo avatar y la modularización completa del sistema de reconocimiento de gestos.

## Hitos Técnicos

### 1. Estabilización de IK (Avatar Mixamo)
- **Problema**: Los codos se doblaban hacia adentro o tenían comportamientos erráticos con el modelo Mixamo.
- **Solución**: Se implementó una configuración específica para rigs de Mixamo:
    - `bendAxis`: Eje Y `(0, 1, 0)`.
    - `poleAngle`: `Math.PI / 2` (90 grados) para que los codos apunten hacia afuera/atrás.
- **Resultado**: Movimiento natural de brazos, ideal para el entrenamiento de gestos. Se ha estandarizado el uso del modelo local `passive_marker_man.glb`.

### 2. Sistema de Gestos Modular (Arquitectura Movement-Centric)
- **Cambio de Paradigma**: Se ha pasado de un archivo JSON gigante por personaje a un sistema de archivos individuales por movimiento (ej: `kamehameha_preparation.json`).
- **Beneficios**:
    - **Escalabilidad**: Se pueden compartir movimientos entre personajes (Goku y Vegeta comparten `recharge`).
    - **Eficiencia**: El entrenamiento solo sincroniza el archivo del movimiento modificado, no todo el modelo.
    - **SSOT**: Se ha eliminado la dependencia de `localStorage`, centralizando el almacenamiento en el servidor (`server/data/gestures/`).
- **Estandardización**: Se ha reforzado la regla de que cada técnica debe tener al menos 2 fases (`prep` + `active/firing`) para garantizar la robustez del FSM y el árbol de decisión.

## Decisiones Clave (SSOT)
- Los nombres de los archivos en el servidor coinciden exactamente con los labels del GSS.
- `GestureSkillSystem.switchCharacter` ahora realiza cargas paralelas de los movimientos configurados en `CharacterConfigs.ts`.

### 3. Refinamientos de UI y Estética VR
- **PowersGuidePanel**: Se eliminaron las descripciones pequeñas y se aumentaron los botones a 120x60px con fuente de 32px para mejorar la accesibilidad en VR.
- **VFX Sync**: Implementación de `onChargeUpdate` para que los orbes de energía sigan el centro de las manos en tiempo real usando `XRHandsContext`.
- **Extractor Optimization**: Implementación de cambio dinámico de extractores (`wristOnly` para preparación, `wristAndFingertips` para ejecución) mejorando el hit-rate y el rendimiento.
