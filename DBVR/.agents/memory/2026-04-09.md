# 2026-04-09 — Configuración de WebXR y Meta Quest Link

## Resumen
Hoy se identificó un obstáculo crítico para el desarrollo de gestos con el Meta Quest 3: el modo "Remote Desktop" (Escritorio Remoto) no transmite datos de WebXR (Hand Tracking) al PC. Se documentó la solución oficial utilizando Meta Quest Link.

## Problema Detectado
- El usuario intentaba capturar gestos usando una aplicación de escritorio remoto.
- El juego (BabylonJS/WebXR) no recibía datos de las manos, reportando modo desktop.
- **Causa:** El protocolo de escritorio remoto estándar solo transmite video/audio/teclado, no el passthrough de sensores VR necesario para las APIs de WebXR en el navegador del host.

## Solución Documentada
1. **Hardware:** Usar cable USB-C de alta velocidad (Quest Link) o Wi-Fi 5/6 (Air Link).
2. **Software PC:** App de Oculus instalada y configurada como "Active OpenXR Runtime".
3. **Hand Tracking:** Debe estar habilitado tanto en el visor como en el panel de dispositivos de la app de PC.
4. **Navegador:** Chrome o Edge son obligatorios para soporte robusta de Hand Tracking en Windows.

## Impacto en el Proyecto
Esta información es vital para cualquier sesión de entrenamiento de gestos (GSS), ya que sin una conexión de datos VR real, el clasificador KNN no puede recibir los tensores de posición de las articulaciones.
